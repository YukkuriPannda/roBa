# PLAケースの強度チェック

この文書は個人用の試作判定手順。形状の合格、解析上の合格、試作の合格を別に記録する。プリンター、PLA製品、ノズル、荷重が未確定の現在は、強度の最終合格を出さない。

## 印刷条件を固定する

記録する項目はプリンター・ノズル径・実際の線幅・層高・フィラメント製品とロット・乾燥状態・温度・冷却・外周数・上下層厚・インフィル・造形方向・サポート・スライサーとプロファイル版。部品ごとの造形方向は画像でも残す。

初回の比較用仮条件はノズル0.4 mm、層高0.2 mm、外周4本、上下層厚1.0 mm以上、インフィル30%。温度は製品メーカーの指定範囲とプリンターの検証済みプロファイルを使う。これは検証の出発点として本プロジェクトが選ぶ条件であり、強度保証値ではない。実機情報が分かったら置き換える。

## 毎回の確認

| 確認 | 判定・対処 |
|---|---|
| BRep | 最終部品は有効で期待するソリッド数。元形状を保持する追加改造では `元形状 - 改造形状` の体積が数値許容差内でゼロ |
| 出力メッシュ | 閉じたメッシュ、非多様体・縮退面・反転を確認。できない検査は未確認とする |
| 寸法・嵌合 | 外形、穴、爪、相手部品、左右、組み付け経路を確認。公差は試験片で決める |
| 肉厚 | 新規の剛性壁は実線幅4本分、荷重を受ける付け根は6本分を初回レビュー目安にする。満たしても自動合格にはしない |
| 薄肉・局所部 | 薄い爪・ヒンジ・孔周辺は局所断面と最薄部を測る。スナップは上の剛性壁基準と分け、必要変位・ひずみを確認 |
| 応力集中 | 脚・ボス・ヒンジの付け根に補強と丸みを検討。薄い首、鋭い内角、孔間の短い残肉を重点確認 |
| 積層方向 | 曲げや引張で層間が開く方向を避ける。スライサーで外周の連続性、空洞、サポート除去経路を確認 |
| 接触と動作 | 収納、展開、途中の動作、ストッパー、ガタ、脱落、机上の滑りを確認 |

全体の自動肉厚検査がない場合、代表点の確認だけで全体合格としない。重点箇所の測定表と断面画像を残す。変更した寸法の連動で爪・相手部品・クリアランスが変わる場合は再検査する。

## 解析が必要になる変更

支持脚、ヒンジ、ストッパー、ネジボス、手荷重を受ける部位、長い片持ち、肉薄化、材料や造形方向の変更は解析対象の候補。今回の折り畳み脚は対象に含める。小さな飾りや荷重を受けない配置変更は、理由を記録して解析を省略できる。

先に使用時の力・方向・位置、支持点、両脚への分配、組立時の押し込み力、繰り返し回数、使用温度を設計カードに書く。未定なら荷重を仮定して感度を調べることはできるが、最終合格は保留する。

FreeCAD FEMを使う場合はソルバー・メッシュ・拘束・接触・材料定数を保存する。材料は製品データと同条件の試験片を優先し、汎用PLAの等方性材料は予備比較に限定する。Z方向の弱さ、クリープ、疲労は等方性の静解析だけでは判定できない。スナップ組立は大変形・接触があるため、小変形の静解析だけで可否を決めない。

強度の数値判定には同条件の根拠ある許容値を使い、初回の目標安全率を2以上とする（本プロジェクトの暫定方針）。許容値の根拠がない場合は応力・変位の比較結果のみ報告する。変位限界はPCB、接触部、ガタの許容値から決める。メッシュを細かくした結果も比較し、応力特異点と実際の破損候補を分ける。

## 試し刷りと実物判定

最初は実際と同じ造形方向でヒンジ受け・軸・デテントの小片を印刷する。押し込みで白化・割れ・層間剥離が出たら不合格。寸法または機構を見直し、無理に押し込まない。

小片の後に全体を印刷し、実物への嵌合、収納・展開、ストッパー、安定性を確認する。合意した使用荷重を段階的に加え、初回の試作では100回の開閉と24時間の使用荷重保持を記録する。これは初期不具合を探すスクリーニングで、耐用寿命の保証ではない。試験中の支持を確保し、基板・電池を破損させない構成で行う。

割れ、白化、永久変形、層間剥離、脚の脱落、ストッパー越え、使用に支障のあるガタは不合格。試験前後の寸法と写真、荷重、温度、開閉回数を記録する。造形条件を変えたら関連する試験をやり直す。

## 記録テンプレート

```text
変更ID / コミットまたはコードハッシュ:
対象 / FCStd / STEP / STL:
印刷プロファイルID / フィラメント:
形状: 合格 / 不合格 / 未確認（検査結果・断面画像）
荷重条件 / 温度 / 目標寿命:
解析: 合格 / 不合格 / 比較のみ / 省略（根拠・結果）
試験片: 合格 / 不合格 / 未実施
実物嵌合 / 開閉 / 荷重保持: 合格 / 不合格 / 未実施
総合: 試作候補 / 使用条件内で確認済み / 不合格
未確認事項 / 次の確認:
```

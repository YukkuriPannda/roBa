# 個人用roBa v3ケースの改造

対象はv3通常トップと左右底面。実物の世代は暫定なので、印刷前に爪・穴・PCB・トラックボール周辺を照合する。既存の折り畳みテンティング改造を引き継ぎ、FreeCADで追加形状を変更できるようにする。

## データの役割

| データ | 役割 |
|---|---|
| `case/v3/*.stp` | 上流由来の基準形状。直接上書きしない |
| `case/v3/tenting/` | 引き継いだCadQuery版と過去の検査記録。比較・参照用 |
| `case/v3/freecad/` | FreeCAD版の生成コード、マクロ、ネイティブ文書、検査結果 |
| `.FCStd` | 基準形状、パラメーター、追加形状を保持する編集用文書 |
| STEP / STL | 交換用 / スライサー用の出力。編集元にはしない |

元のSTEPには元CADのスケッチ履歴が含まれない。FreeCADへの移植でその履歴が復元されるわけではない。基準形状を保持し、新規の機能を再計算できる履歴として追加する。生成コードと寸法が再現用の正本で、FCStdを手で変更した場合は採用する値をコードへ戻して再生成する。手作業だけの変更を再生成で消さないよう、先に別名保存する。

収納デテントの曲面は、旧STEPから取り出したBRepを参照形状として保持する。FreeCADの標準ロフトで曲面を作り直すと旧形状に差が出るため、今回は元の曲面を維持し、取り付け位置をパラメーターで変更する。デテント自体の曲面・半径の再設計は別の変更として扱う。

FreeCAD Pythonの外部モジュールを使う文書は、モジュールが見つかる環境で開く必要がある。FCStdだけを別のPCへ渡して編集可能と扱わず、生成コードと起動マクロも一緒に渡す。具体的な起動・再生成手順は[FreeCAD版のREADME](../case/v3/freecad/README.md)を参照。

## 自然言語の要望から変更する

「磁石を付けたい」「脚の角度を変えたい」などの要望を出発点にする。AIは既存データを調べ、次の設計カードを埋めてから変更する。見た目から決められる軽微な値は仮定を明記し、部品寸法・使用荷重・嵌合など結果を左右する不明点は質問する。

```text
目的 / 使用場面:
対象パーツ / 左右:
機能と取り付け位置:
寸法 / 可変範囲 / 根拠:
維持する穴・爪・接触面:
相手部品の寸法 / 公差:
荷重 / 荷重方向 / 繰り返し / 温度:
印刷プロファイルID / 造形方向:
形状の受入条件:
強度の受入条件 / 試し刷り方法:
未確定事項:
```

作業は目的別ブランチで行い、基準形状から追加機能を分け、意味のある名前とmm・度単位を付ける。左右の構造差を確認し、全体を単純ミラーしない。PCB、電池、配線、スイッチ、エンコーダ、USB、トラックボール、底面の爪との干渉を検査する。実物の位置が分からない箇所は「未確認」と記録する。

変更ごとに再生成、形状検査、再読み込み、主要寸法の編集・再計算を確認する。画像と検査記録を残し、[PLA強度チェック](pla-strength-check.md)に沿って解析・試作の要否を判断する。失敗時は直前のFCStdを戻すか、採用済みパラメーターから再生成する。検査失敗した出力を印刷候補として扱わない。

## 引き継ぐテンティング機構

既存案は軸直径3.0 mm、受け内径3.4 mm、挿入口2.65 mm、脚厚2.7 mm、展開角65度。支持間隔110 mmと既存底面角4度を使った公称傾斜は約15度。寸法は既存案を再現するための値で、PLAでの耐久性が確認された値ではない。

収納デテントの球半径1.5 mmに対し穴半径1.4 mmで意図的な干渉がある。ヒンジ挿入口も軸より狭い。したがって干渉体積ゼロだけを合格条件にせず、収納・展開・回転途中の接触位置と試し刷りを確認する。既存コードの端点干渉上限2 mm³は再現比較の基準で、機構の安全性・開閉可能性を証明しない。

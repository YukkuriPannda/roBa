## 実行した確認

FreeCAD同梱Python、FreeCAD 1.1.4で確認した。

| 確認 | 結果 |
|---|---|
| `build_verify.py` | PASS。生成、別プロセスでの再読込・寸法変更・復元、最終再読込・出力 |
| BRep | 脚・左右の改造底面は有効な単一ソリッド。元底面の材料を保持 |
| 収納／展開端点 | 既存案の干渉上限2 mm³以内。全可動範囲の証明ではない |
| STL | 脚824面、左6230面、右7072面。閉鎖性、辺の多様体性、面の向き、縮退面検査に合格 |
| STEP再読込 | 体積相対差0.02%以内、解析形状の外形差0.02 mm以内、双方向のサンプル距離0.005 mm以内 |
| 独立した旧形状との比較 | 双方向の表面サンプル距離の最大値は約8.17e-8 mm。サンプル比較であり完全同一性の証明ではない |
| 編集後の出力 | 脚長20→21 mmで再計算・保存・出力に合格。標準出力を変更しない試験用コピーで実行 |
| 不正寸法 | 軸半径2 mm・受け半径1.7 mmの矛盾を拒否。直前の出力を保持し、最新状態をFAILとして記録 |
| 保存内容と記録 | 編集後のFCStdハッシュと出力記録が一致。開き直すと採用した脚長21 mm・元の軸半径1.5 mmを保持 |
| 配布場所への移動 | 一式を別フォルダーへコピーし、成果物ハッシュ、相対パス、FCStd再読込と厚み変更の再計算に合格 |

旧STEPをFreeCADで書き出し直すと、変更のない元底面でも体積値に約2.547 mm³の差が出た。境界上のサンプル点はほぼ一致したため、体積完全一致の判定をやめ、相対差・解析境界箱・双方向の点と形状の距離を組み合わせた。境界箱は表示用三角形キャッシュに影響されない `optimalBoundingBox(False, False)` を使う。

再確認コマンドは[操作手順](../case/v3/freecad/README.md)を参照。詳細な数値とハッシュは `case/v3/freecad/generated/freecad_build.verified.json` に保存した。配布用コピーには独立した検査と編集後の出力試験のJSONも添付した。

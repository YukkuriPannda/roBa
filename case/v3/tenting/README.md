# v3 折り畳み式テンティングスタンド

roBa v3 の左右底面に、別部品のピンやネジを使わない折り畳みスタンドを追加します。左右それぞれの構成部品は、ヒンジ受けを一体化したケース底面と、左右共通のスタンドの2点です。

## 設計条件

- 既存の `bottom_L.stp` / `bottom_R.stp` を正とし、元形状には穴あけや切削を行わない
- ケース側のC形受けへ、スタンド一体の直径3.0 mm軸を押し込むスナップ式ヒンジ
- 軸と受けの半径クリアランスは0.20 mm、挿入口の干渉は直径方向で0.35 mm
- 収納時は2つのボールデテント、展開時はスタンド一体のカムで65度に止める
- v3底面の既存4度と合わせ、支持間隔110 mmで公称約15度
- 左右のスタンド形状は共通。ネジ、金属ピン、磁石は不要

## 生成

CadQuery 2.8以降で次を実行します。

```powershell
python .\case\v3\tenting\build_tenting.py
```

`output` に左右のケース底面と共通スタンドのSTEP/STL、および検証記録を出力します。

## 造形と組み立て

スタンドは広い面を造形ベッドへ向け、ケース底面は従来どおり外面を下にして造形する想定です。ケース側のC形受けへスタンド軸を真下から均等に押し込みます。材料や積層方向によってスナップ量が変わるため、初回は受け1個分の試し刷りを推奨します。

実機荷重、繰り返し開閉寿命、机上での滑り、およびスライサー上のサポート要否は未確認です。

# 34mmボール用・3点ベアリングケース

通常版 `case/trackballcase.stl` を基準にした派生モデルです。v3通常トップ・右底面を相手形状として使います。元STL、本体STEP、既存テンティングのファイルは変更しません。検査結果は `latest_run_status.json` と実行先の `verification.json` を確認してください。`FAIL_NOT_PRINT_READY` の実行を印刷候補として扱わないでください。

## PLAの初回プリント

ノズル径は0.4mm。積層高は0.2mm、外周3本（線幅換算1.2mm）、上下層1.0mm以上、インフィル30〜40%（gyroid）から始めます。外周3本は印刷指定の値で、[PLA強度チェック](../../../../doc/pla-strength-check.md)の比較用仮条件（外周4本）とは異なるため、強度比較では両方を試してください。温度・冷却・線幅・速度はPLA製品のメーカー指定とプリンターで検証済みのプロファイルに合わせます。これらは初回試作条件であり、強度保証ではありません。

印刷に使うファイルは [`generated/print/`](generated/print/) だけです。詳細な設定と向きは [`generated/print/PRINT.md`](generated/print/PRINT.md) を参照してください。

- `trackball_bearing_case_print.stl`: ケース本体。元の座標のZ軸を造形Zに揃え、フランジ下面（元のZ=2mm付近）を造形面に置く。ベアリング軸を水平に保つための向き。この向きでは45度超の未支持面が約771mm²あり、サポートが必要。ベッド接触は約262mm²なので、ブリムを推奨。
- `fit_coupon_print.stl`: 3段の試験片。穴の軸を水平に保つため、底面を造形面に置く。穴は丸い下穴を含むため、約49mm²の未支持面（主に丸い下穴の底）が残る。

どちらもXY中心を原点付近に置き、最低点をZ=0にしてある。FlashPrintでプロファイルを設定してスライスし、サポートとブリムをプレビューで確認してください。機種別プロファイルが未指定のためG-codeは作成していません。

最初に`fit_coupon.stl`で穴・ビス・金属スペーサー・ベアリングの組付けを確認してからケースを試作します。ボール側ウェブは解析値0.82mmで剛性壁の目安1.6mmも下限1.2mmも下回ります。全体肉厚は未検査です。全体肉厚・実荷重・PLAの耐久性は未検査です。ケースは印刷できるSTL形状としてCAD検査済みですが、初回の外観・組付け試作用であり、使用強度の承認はありません。

M2ビスのねじ山が内径2.0mmに通ること、軸として支障がないことは実部品で未確認です。ベアリングの外輪・シールドを押さえる締め方は使いません。ねじを強く締めて樹脂ボスを破損させないよう、先に試験片で確認します。

通常の大きな頭ではボールに接触するため、小頭を使います。頭径3.8mm・頭高さ1.3mmは仮定値です。Mini 4WDのM2ビス（首下6mm）の寸法は購入品で確認してください。公差・面取り・首下形状は未確認です。

## 生成と検査

FreeCAD 1.1同梱のPython、NumPy、SciPyを使います。リポジトリのルートで実行します。

```powershell
$freecadBin = Join-Path $env:LOCALAPPDATA 'Programs\FreeCAD 1.1\bin'
& (Join-Path $freecadBin 'python.exe') 'case\v3\freecad\trackball_bearing\build_verify.py'
```

各実行は `runs/<日時>/` に出力します。検査が全て通った実行だけを `generated/` にコピーします。失敗時は `latest_run_status.json` に失敗と実行先を残し、過去の出力を新しい合格として扱いません。STLは0.08mmの形状偏差上限で局所修復し、保存・再読込後の閉鎖性、自己交差、非多様体辺、表面偏差を検査します。float32保存で交差位置が移る場合は、新しい位置と未訪問メッシュ状態を条件に局所修復を続け、最終メッシュが交差ゼロで偏差上限内のときだけ合格します。直接 `bearing_case.py` を実行した生成物も、検証前は候補です。

元のSTL・本体STEPのハッシュが計測時と異なる場合は停止します。形状が変わった入力に古い支持位置や配置変換を流用しません。寸法を編集した文書を保存しただけでは、STEP/STLと検査結果は更新されません。採用する寸法を生成コードに戻し、再生成・検査してください。

印刷用ファイルは `export_print.py` が最終STLから作る。24通りの立方体回転のうち、ベアリング軸の水平条件を満たすものから、45度超の未支持面が最小になる向きを選ぶ。同じ条件で、閉じたメッシュ・自己交差なし・最低点Z=0・XY中心0・体積一致を確認し、合格したものだけ `generated/print/` に公開する。サポートの有無はこの幾何的な判定であり、スライサーのプレビューで必ず確認すること。

## FreeCADで開く

`Open_Bearing_Case.FCMacro` をFreeCADのMacroメニューから実行します。Pythonモジュールを読み込んでから文書を開くため、寸法変更でケースと相手部品を再計算できます。FCStdだけを別PCに渡さず、このフォルダーのコードとマクロも一緒に渡します。

`Dimensions` にmm・度単位の寸法があります。`BearingCase` とベアリング・ビス・スペーサー・ボール・試験片は、同じ寸法オブジェクトを参照します。`OriginalMesh` は未変更の元STL、`SourceSolid` は局所修復したファセット形状です。元CADのスケッチ履歴を復元したものではありません。

## 元メッシュの修復

元STLには自己交差があります。`repair_source.py` は、その周辺の短い辺を局所的に整理し、閉鎖性を維持した派生メッシュを作ります。変更箇所、面数、体積差、頂点・面重心の双方向サンプル距離を `inspect/logs/repair.json` に記録します。表面サンプル差の上限は0.06mm、体積差の上限は0.05mm³です。完全な表面同一性を証明する検査ではありません。

STLの数値丸めで検査結果が変わるため、修復した基準メッシュはFreeCADネイティブのBMS形式で保持し、保存・再読み込み後も検査します。最終の印刷用STLは別途閉鎖性・非多様体・自己交差を確認します。

## 組み付けと試し刷り

1. `print/fit_coupon_print.stl` を本体と同じ材料・条件で試し刷りする。3段は左から、ベアリング座の逃げ0.20/0.30/0.40mm、下穴1.55/1.65/1.75mm。底面を造形面に置く。ベアリング座が外輪に対して締まりすぎず、ガタが大きすぎない段を選んで本体に採用する。
2. 下穴とM2ビスを確認する。必要なタップ加工条件を決め、白化・割れ・層間剥離があれば寸法または条件を見直す。
3. ビス頭、金属スペーサー、ベアリング、金属スペーサー、ボスの順に組む。内輪を保持した状態で外輪が軽く回ることを確認する。
4. ケースを試し刷りし、先に3組のベアリングを組み付ける。工具が本体側に通らない箇所は、本体からケースを外して交換する。
5. 元と同じM1.7固定部で取り付け、34mmボールを載せる。3点の接触、ガタ、擦れ、読み取り、配線・基板への接触を実物で確認する。

## 検査の範囲

検査コードは形状・接触・本体干渉・元形状の保持・メッシュ・STEP再読み込み・寸法変更と保存再読み込みを確認します。支持点の力の釣り合いは重力が支持方向の錐に入るかを計算するだけで、PLAの強度・疲労・保持力を証明しません。

センサー穴と元のボール位置の関係は計測基準として保持しますが、PMW3610の光学中心・基板・配線の実モデルはありません。光学距離、実物嵌合、印刷可能性、全体の最小肉厚、耐久性、回転感は未確認です。ボール側ウェブは解析値0.82mmで目標1.6mm・下限1.2mmを下回り、荷重下の強度判定はHOLDのままです。元形状の面の集まりに対するフィレット・面取りは適用できず、縁の面取りは未適用です。試験片と荷重・造形条件による確認前に、耐荷重部品として採用しないでください。[FreeCAD改造手順](../../../../doc/freecad-workflow.md)と[PLA判定手順](../../../../doc/pla-strength-check.md)に従って試作してください。

## PLA強度チェック（strength_check.py）

[PLA強度チェック](../../../../doc/pla-strength-check.md)に沿った一次スクリーニング。`python strength_check.py` で `generated/strength_check.json` を作る（FreeCAD不要。`bearing_case.py` のDEFAULTSと `generated/build.json`・`verification.json` を読むだけ）。

- **この節の数値は620版（外径6mm・ウェブ1.84mm）のもので、MR42版では再計算していない。**
